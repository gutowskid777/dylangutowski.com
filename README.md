# dylangutowski.com

My portfolio, live at **[dylangutowski.com](https://dylangutowski.com)**.

One HTML file. No framework, no build step. Each of the eight projects on it has a working recreation of its real interface that plays itself on a loop, with invented data, so you can see the product instead of reading about it.

- One small `Demo` class drives every demo: a scripted cursor, a loop that pauses when it scrolls off screen, and a progress line along the bottom.
- The SlopStop demo's idea tree is a port of the real app's drawing code, including the zoom where a branch swings upright and becomes the next trunk.
- The Tenora demo runs a port of the app's own orbit layout.
- Demos keep their desktop proportions on a phone: each one is laid out at a fixed design width and scaled to fit.

Hosted on Vercel.
